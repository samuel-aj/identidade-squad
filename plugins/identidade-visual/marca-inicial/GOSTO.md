# GOSTO — preferências acumuladas

> Isto é **viés, não lei**. O `caca-referencias` e o `diretor-de-arte` leem este
> arquivo porque preferência passada deve enviesar a **busca**.
>
> Nada entra aqui com uma observação só, **exceto o que o usuário disse com todas
> as letras**: declaração vale mais que inferência.

Formato de cada entrada:

```
### <a preferência, em uma frase>
- visto em: <projetos>
- palavras do usuário: "<literal>"
```
